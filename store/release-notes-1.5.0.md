# Google Play Store — Release notes (What's new)

Version **1.5.0**. One block per supported language, wrapped in its Play Store
locale tag. Character limit: **500 characters** per language (Play Console
"What's new" field).

<en-GB>
What's new in 1.5.0:
• Rebuilt as a fully native app: faster start-up and more precise synchronization with your TV
• Audio keeps playing in the background when the TV briefly changes programme
• Companion pages that redirect (for example to HTTPS) now open in the app
• Synchronization also works when a VPN is active or the Wi-Fi has no internet access
Thanks for using Universal MediaSync!
</en-GB>
