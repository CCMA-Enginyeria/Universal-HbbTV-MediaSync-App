# Google Play Store — Release notes (What's new)

Version **1.4.1**. One block per supported language, wrapped in its Play Store
locale tag. Character limit: **500 characters** per language (Play Console
"What's new" field).

<en-GB>
What's new in 1.4.1:
• Companion experiences now open reliably on every device: verified sites open in Chrome, everything else opens in the built-in viewer
• Fixed an error that stopped some companion pages from opening on iPhone and iPad
• The synchronization notification no longer stays active when a companion page fails to open
Thanks for using Universal MediaSync!
</en-GB>
