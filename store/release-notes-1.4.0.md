# Google Play Store — Release notes (What's new)

Version **1.4.0**. One block per supported language, wrapped in its Play Store
locale tag. Character limit: **500 characters** per language (Play Console
"What's new" field).

<en-GB>
What's new in 1.4.0:
• Choose between High precision (DVB-CSS) and Compatibility (App2App) synchronization modes
• The app now checks which synchronization methods each TV supports
• External companion experiences communicate more reliably through Chrome Custom Tabs
• Improved App2App pairing, diagnostics and connection stability
Thanks for using Universal MediaSync!
</en-GB>
