# Google Play Store — Release notes (What's new)

Version **1.6.0**. One block per supported language, wrapped in its Play Store
locale tag. Character limit: **500 characters** per language (Play Console
"What's new" field).

<en-GB>
What's new in 1.6.0:
• TV programmes can now include their own interactive experiences: open them from the app while you listen to or watch the programme
• When an experience is offered in several languages, choose yours from the list
Thanks for using Universal MediaSync!
</en-GB>
