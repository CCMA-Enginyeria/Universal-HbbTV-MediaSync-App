# Google Play Store — Release notes (What's new)

Version **1.7.0**. One block per supported language, wrapped in its Play Store
locale tag. Character limit: **500 characters** per language (Play Console
"What's new" field).

<en-GB>
What's new in 1.7.0:
• Check the audio, video and subtitles you want separately: combine them freely
• The player stays docked at the bottom of the screen
• Subtitles can be shown without playing audio or video, and in XR on Meta Quest
• Interactive experiences open with WebXR in the Meta Quest browser
• More reliable synchronization with the TV
Thanks for using Universal MediaSync!
</en-GB>
